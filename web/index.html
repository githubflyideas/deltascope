Per-process CPU and memory, read directly from /proc — no PCP configuration needed. The server captures a snapshot every 10 minutes, so history builds up on its own. Pick two windows to see who grew and who restarted.

  

  

    

      
      
    

    

    

    
Snapshots the machine now and diffs it against the nearest snapshot before the chosen time — sysctl, packages, kernel modules, network config, listening ports, firewall, mounts, services, cron, config file fingerprints, and security posture. Only what changed is shown. The server captures a snapshot every 10 minutes on its own, so history builds up without any cron job.
